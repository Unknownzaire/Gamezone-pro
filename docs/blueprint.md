# **App Name**: Gamezone Pro

## Core Features:

- Tournament Listing: Display a scrollable list of upcoming and live BGMI tournaments.
- Tournament Joining: Allow users to join tournaments by deducting the entry fee from their wallet balance.
- Wallet Management: Enable users to view their wallet balance and transaction history.
- Profile Management: Let users manage their profile, change password, and log out.
- Admin Dashboard: Provide admins with an overview of users, tournaments, and revenue.
- Tournament Creation: Allow admins to create and manage BGMI tournaments, set prizes, and define match times.
- Winner Declaration: Permit admins to declare tournament winners, distribute prize money, and manage tournament status.  Use a tool for ensuring regulatory compliance in prize disbursal

## Style Guidelines:

- Primary color: Deep Indigo (#6666FF) for a sophisticated and competitive feel.
- Background color: Dark slate gray (#2A2A35), providing a high contrast, modern feel.
- Accent color: Electric Purple (#BF40BF) to highlight important CTAs.
- Body and headline font: 'Space Grotesk' (sans-serif) for a modern, techy feel. If longer text is anticipated, use this for headlines and 'Inter' for body.
- Use Font Awesome icons throughout the application for a consistent and professional look.
- Mobile-first design with a centered, fixed-width container (360-420px) for a native app-like experience.
- Subtle transitions and animations to enhance user experience, like fade-in effects and button presses.
